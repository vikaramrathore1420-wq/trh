TRH Travel & Expeditions — GitHub Pages
A static, mobile-friendly travel website for TRH Travel & Expeditions, including the homepage and the Unwinding in Sainj expedition page.
Publish on GitHub Pages (free)
Create a new GitHub repository.
Extract this ZIP.
Upload the contents of the extracted folder — `index.html`, `sainj.html`, `README.md`, and the complete `assets/` folder — to the repository root. Do not upload the ZIP itself or nest these files inside another folder.
Commit/push the files to the `main` branch.
In Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, then Save.
Open the Pages URL shown by GitHub. The homepage is `index.html`; the Sainj expedition page is `sainj.html`.
Folder structure
```text
index.html
sainj.html
README.md
assets/
  ladakh-drone.mp4
  unwinding-sainj-hero.mp4
  trh-logo.png
  ...photos used by the pages...
```
Notes
Booking enquiries are sent to WhatsApp; the Sainj page also offers an email draft. These are enquiry links, not an online payment or instant-confirmation system.
The Sainj expedition dates and rate are displayed in the HTML and should be reviewed before publishing.
Video autoplay depends on browser/device settings and normally requires muted playback.
All media paths are relative (`assets/...`) so the site works from a GitHub Pages project URL.
